# ExampleCore

This folder contains reusable behavior owned by the addon:

- `ThermalMachine` extends DoriosCore `Machine` with heat mechanics.
- `ExampleGasGenerator` extends DoriosCore `Generator` with a gas-fuel conversion method.
- processing helpers centralize direct scripted recipe cycles and placeholder expansion.

Rename this folder to `ADDONNAME_CORE` in a real addon. Never move these classes into DoriosCore merely to make imports shorter.
