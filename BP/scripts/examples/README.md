# Runtime examples

Each subfolder demonstrates one category while importing DoriosCore exclusively through `DoriosCore/index.js`:

- `blocks`: lightweight component-only generators;
- `machines`: direct scripted processing with items, liquids, gases, and upgrades;
- `generators`: passive, liquid-fueled, and gas-fueled energy production;
- `agriculture`: a custom crop lifecycle;
- `multiblocks`: controllers, component scaling, activation, and link-node ports.

Data shared with UtilityCraft lives in `../config`. Reusable addon classes live in `../ExampleCore`.
